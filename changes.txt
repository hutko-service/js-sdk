10.11.2026 => 2.1.0
    * Apple Pay in the third-party desktop browsers (Chrome, Edge, Firefox): the payment is confirmed on an iPhone via
      the QR code; Apple Pay JS SDK (1.latest) is loaded only when there is no native ApplePaySession and the gateway
      allows Apple Pay
    * Apple Pay uses ApplePaySession instead of PaymentRequest; the button is shown only if supportsVersion() and
      canMakePayments() are true (no Apple Pay on Android); a failed merchant validation aborts the session
    * Google Pay: show() is called without canMakePayment() (the user gesture is kept), pay.js is preloaded only when
      the gateway allows Google Pay
    * allow="payment" on the API and button iframes
    * The buttons are shown when the method is supported by both the browser and the gateway, in the "methods" order
    * README: "Apple Pay" and "Content Security Policy" sections; tests: test/apple-pay.test.js
